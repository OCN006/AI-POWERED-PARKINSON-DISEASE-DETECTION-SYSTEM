# Parkinson's Disease Detection from Handwriting

Detecting Parkinson's disease from spiral/wave handwriting drawings using
deep learning, with a focus on rigorous evaluation: subject-level data
splitting, cross-dataset external validation, and statistical significance
testing — evaluation practices largely absent from prior work in this space.

---

## 1. Research Contribution

Most prior work on this task (HandPD/NewHandPD spiral classification)
reports high accuracy (88-98%) but:
- trains and tests on the *same* small dataset, risking overfitting to
  that dataset's specific collection quirks
- rarely tests whether the model generalizes to a *different*,
  independently-collected dataset of the same task
- rarely reports whether an architectural change (e.g., adding attention)
  produces a *statistically significant* improvement, vs. relying on raw
  accuracy differences that could be noise

This project addresses all three gaps:
1. **Subject-level stratified 5-fold cross-validation** — no person's
   drawings appear in both train and validation, preventing identity
   leakage from inflating scores.
2. **External validation** — models are trained only on HandPD and tested,
   completely untouched, on NewHandPD (a separately collected dataset).
3. **McNemar's statistical test** — used to check whether the proposed
   CBAM attention model's predictions differ significantly from the
   baseline, rather than trusting accuracy deltas alone.

## 3. Environment Setup

**Python version matters**: use **Python 3.10**. Python 3.14 has no
TensorFlow wheels available at all; TensorFlow 2.16+ bundles Keras 3,
which has known `from tensorflow import keras` import failures on
Windows. `requirements.txt` pins `tensorflow==2.15.0` specifically to
avoid this.

```powershell
py -3.10 -m venv ocn
ocn\Scripts\activate
pip install -r requirements.txt
```

## 4. Pipeline, in order

### Step 1 — Data pipeline (`data_pipeline.py`)
Parses both datasets into unified manifest CSVs, with **subject-level**
stratified 5-fold splitting on HandPD (grouped by subject ID so no
person's images cross fold boundaries). NewHandPD gets no fold assignment
— it's tagged `external_test` and reserved entirely for later.

```powershell
python data_pipeline.py --check   # verify parsing before the real run
python data_pipeline.py           # generates data/manifests/*.csv
```

### Step 2 — Baseline model (`train_baseline.py`)
EfficientNetB0 (ImageNet pretrained), two-phase training: frozen backbone
+ head-only (LR 1e-4), then unfreeze last 25% of backbone and fine-tune
(LR 1e-5). Weighted binary cross-entropy for class imbalance. Checkpointed
and early-stopped on validation **PR-AUC** (not accuracy — more
appropriate for HandPD's imbalance).

```powershell
python train_baseline.py --fold 0 --check_data   # sanity check first
python train_baseline.py --fold 0                # then for folds 0-4
```

### Step 3 — CBAM model (`cbam.py` + `train_cbam.py`)
Same backbone, same training protocol as baseline — the only difference
is a CBAM (Convolutional Block Attention Module) block inserted after the
backbone's final conv feature map (`7x7x1280`), before pooling. Channel
attention + spatial attention in sequence, per the original CBAM paper.

```powershell
python train_cbam.py --fold 0   # then for folds 0-4
```

### Step 4 — Aggregate results (`aggregate_results.py`)
Computes mean ± std across all 5 folds for both models. Edit the
`FOLD_RESULTS` dict with each fold's printed metrics, then run:

```powershell
python aggregate_results.py
```

### Step 5 — McNemar's test, in-distribution (`mcnemar_test.py`)
Pools out-of-fold predictions across all 5 folds (each image predicted
exactly once, by the fold that held it out) into one 736-image paired
comparison between baseline and CBAM.

```powershell
python mcnemar_test.py
```

### Step 6 — External validation (`external_validation.py`)
Evaluates all 5 baseline and all 5 CBAM checkpoints on the untouched
NewHandPD set, reports mean ± std, and runs McNemar's test using an
ensemble (5-fold-averaged) prediction per model.

```powershell
python external_validation.py
```

### Step 7 — Grad-CAM visualizations (`grad_cam.py`)
Generates heatmap overlays showing which parts of the spiral/wave the
model focused on, for a mix of correctly and incorrectly classified
examples. **Not yet run** — next step.

```powershell
python grad_cam.py --checkpoint outputs/baseline_fold0_best.keras
python grad_cam.py --checkpoint outputs/cbam_fold0_best.keras
```

### Utility — single-image testing (`predict.py`, `predict_ensemble.py`)
Quick tools to test the model on any individual image, either with one
checkpoint (`predict.py`) or averaged across all 5 folds
(`predict_ensemble.py`, generally more reliable).

```powershell
python predict.py --checkpoint outputs/cbam_fold0_best.keras --image path/to/image.jpg
python predict_ensemble.py   # edit IMAGE_PATH / MODEL_TYPE at top of file, then run
```

## 5. Results So Far

### 5-fold CV on HandPD (in-distribution)

| Metric | Baseline | CBAM |
|---|---|---|
| Accuracy | 0.834 ± 0.127 | 0.830 ± 0.084 |
| Precision | 0.957 ± 0.050 | 0.958 ± 0.049 |
| Recall | 0.827 ± 0.139 | 0.824 ± 0.093 |
| ROC-AUC | 0.884 ± 0.119 | 0.887 ± 0.107 |
| PR-AUC | 0.962 ± 0.045 | 0.961 ± 0.044 |

**Finding**: CBAM doesn't improve mean accuracy, but meaningfully reduces
fold-to-fold variance (std) on accuracy, recall, and ROC-AUC — a
consistency improvement rather than a raw performance improvement.

### McNemar's test (HandPD, pooled out-of-fold, 736 images)

- Contingency table: 584 both-correct, 28 baseline-only-correct,
  22 CBAM-only-correct, 102 both-wrong
- Statistic: 22.0, **p = 0.4799** — not statistically significant

### External validation on NewHandPD (528 images, never trained on)

| Metric | Baseline | CBAM |
|---|---|---|
| Accuracy | 0.873 ± 0.018 | 0.858 ± 0.024 |
| Precision | 0.917 ± 0.019 | 0.924 ± 0.010 |
| Recall | 0.802 ± 0.045 | 0.761 ± 0.064 |
| ROC-AUC | 0.942 ± 0.030 | 0.934 ± 0.028 |
| PR-AUC | 0.935 ± 0.030 | 0.931 ± 0.022 |

**Finding**: both models generalize *well* to the external dataset —
performance held steady or even improved slightly compared to HandPD CV,
and with notably lower variance. This is a positive robustness finding
(models aren't just memorizing HandPD-specific quirks), though the
direction (external > in-distribution) is somewhat unusual and likely
reflects NewHandPD's more standardized collection protocol and more
balanced classes. Recall dropped somewhat externally for both models
(0.80 baseline, 0.76 CBAM) — worth flagging as a limitation since
sensitivity is the clinically costlier metric to miss on.

### McNemar's test (NewHandPD, ensemble predictions, 528 images)

- Contingency table: 452 both-correct, 9 baseline-only-correct,
  6 CBAM-only-correct, 61 both-wrong
- Statistic: 6.0, **p = 0.6072** — not statistically significant

**Overall conclusion so far**: CBAM's contribution is improved
consistency/robustness across subject subgroups, not a statistically
significant accuracy gain. Both models generalize well cross-dataset.
This is an honest, defensible finding for the paper even though it isn't
"CBAM wins" — the rigor of testing it properly (subject-level splits,
external validation, significance testing) is itself the contribution.

## 7. Environment Troubleshooting Log

(kept here in case the environment needs rebuilding later)

- **Python 3.14**: no TensorFlow wheels exist yet — must use 3.10 or 3.11
  (avoid Microsoft Store Python installs — they're unreliable for venvs)
- **TensorFlow 2.16+**: bundles Keras 3, causes
  `ImportError: cannot import name 'keras' from 'tensorflow'` on Windows
  — fixed by pinning `tensorflow==2.15.0`
- **Loading CBAM checkpoints**: requires `safe_mode=False` in
  `keras.models.load_model()`, since CBAM's spatial attention uses Python
  `lambda` functions that Keras 3's safe-loading blocks by default
